# M32 — M28 historical Edge Function verifier synchronization

M28 certified one shared `EdgeFunctionClient` composed from authenticated transport and diagnostics. M32 adds an optional observability dependency to the same client so governed Edge Function calls can emit correlated spans. The M28 verifier is synchronized to accept the original two-argument composition or the later three-argument composition. Its authorization, allowlist, JWT, origin, secret-isolation, timeout, response-validation, and server-only credential requirements remain unchanged.
