# M37 → M36 Historical Verifier Synchronization

M36 established Architecture 44. M37 advances the application manifest to Architecture 45 while retaining the M36 production-cutover authority unchanged.

The M36 verifier must therefore accept application architecture versions **>= 44**, while still requiring the M36 target's own Architecture 44 baseline declaration. This is a historical-verifier compatibility synchronization only; it does not weaken M36 cutover requirements.
