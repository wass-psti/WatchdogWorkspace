# Futuristic Minimalist Application Shell Governance — M81

## Ownership
- Stage I M81 owns the typed shell composition boundary and semantic shell/page-frame markers.
- M68 and Shell M1–M8 remain the certified behavior/presentation compatibility authorities.
- M40 remains route lifecycle/ownership authority.
- M11/M14/M66 remain global overlay/menu authority.
- Client-state remains the navigation preference authority.

## Stable hierarchy
`application shell → global navigation → shell header → navigation scroll/sections → navigation status → global page frame → route content`

## Responsive policy
- Desktop retains expanded/compact navigation, persisted width and pin state.
- Unpinned compact preview overlays content and must not cause route-host replacement.
- Mobile navigation remains modal and makes workspace content inert while open.
- Route/content hosts remain page-lifetime stable across shell state changes.

## Accessibility
- Skip link continues to target `#main`.
- Main navigation landmark remains explicitly named.
- Mobile navigation exposes dialog/modal semantics.
- Resize control remains a keyboard-operable separator.
- Navigation state announcements remain polite.

## Performance
M81 adds no new global stylesheet or CSS authority. The existing certified initial CSS ceiling remains unchanged.
