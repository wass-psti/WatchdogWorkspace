# M84 Boards Visual Migration Governance

M84 owns Board presentation only. M45–M52 remain semantic/runtime authorities. The new stylesheet must load after `boards-ui-migration.css`; it may refine visual hierarchy, density, responsive composition, feedback and accessibility presentation, but may not disable controls, change runtime hooks, status IDs, data attributes used by behavior, persistence/realtime/RBAC decisions, or drag/drop ownership.
