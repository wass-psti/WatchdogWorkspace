# Start Here — Phoenix Code

1. Extract the project ZIP.
2. Open the extracted `Material-Tracker-Standalone` folder in Phoenix Code.
3. Open Phoenix Code's terminal.
4. Run `npm install` once.
5. Run `npm run dev`.
6. Open `http://localhost:5173` in the preview/browser.
7. Your test records are saved locally in `server/data/db.json`.

The frontend does not contact monday.com. During this test phase, material data is written to the local Node backend and JSON file.
