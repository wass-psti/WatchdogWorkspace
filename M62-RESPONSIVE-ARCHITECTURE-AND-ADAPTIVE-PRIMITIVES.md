# Milestone 62 — Responsive Architecture & Adaptive Primitives

M62 establishes one shared responsive vocabulary above M61 without rewriting certified feature/module layouts. It governs named breakpoints, query-unit policy, explicit adaptive grid/cluster behavior, and the shared page-gutter transition. Existing feature-specific responsive rules remain compatibility authorities until their migration milestones.

## Certified breakpoint vocabulary

| Name | CSS px | rem equivalent |
| --- | ---: | ---: |
| narrow | 640 | 40 |
| tablet | 840 | 52.5 |
| laptop | 1120 | 70 |
| wide | 1440 | 90 |

M62 introduces no new breakpoint values.
