# M61 — Layout, Grid & Spatial System

M61 establishes a semantic spatial layer over the certified M58 spacing scale and extends the existing design-system layout primitives without changing their default computed geometry. It adds a governed content-width model (`content`, `reading`, `full`), explicit static grid columns, semantic gap roles, and a `WMContainer` primitive.

M61 does not redesign shell, Boards, or embedded application layouts. Responsive breakpoint behavior remains M62-owned.
