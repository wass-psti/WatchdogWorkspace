# M81 — Application Shell & Global Navigation

M81 promotes the already-certified shell behavior into a Stage I Futuristic Minimalist application-shell composition boundary without rewriting routing, authorization, persistence, module lifecycle, or business logic.

Scope: application shell, primary/secondary navigation, sidebars, headers, global page frame, responsive shell behavior, stable hierarchy and navigation-regression protection.

The implementation reuses the certified M68/Shell-M1–M8 geometry and interaction behavior, the M79 token/theme authority, and the M80 shared primitive layer. It adds typed shell composition primitives and explicit semantic markers to the existing page-frame/header hosts. No new global CSS payload is introduced because the M31 initial CSS budget is already at its certified ceiling.
