# Stage C M10 React Shell Activation Runbook

Prerequisite: Stage B M9 must be `active-certified`.

Primary commands:

```bash
npm run react-shell:check
npm run typecheck
npm run verify:ui
npm run stage-c:certify
npm run react-shell:status
```

A successful release promotion ends with `Stage C platform certification: PASS` and M10 `active-certified`.
