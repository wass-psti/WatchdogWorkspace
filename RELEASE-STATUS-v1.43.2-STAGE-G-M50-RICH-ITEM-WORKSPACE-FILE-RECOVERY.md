## Checkpoint 03 — Form-successful-controls and opaque file-ID corrective

The governed Checkpoint 02 Mac run again stopped fail-closed in the dedicated five-scenario M50 Playwright authority with the same three scenarios failing. Root-cause tracing identified two implementation defects that Checkpoint 02 had not corrected. First, `submitProperty` disabled every form control before constructing `FormData`; disabled controls are not successful form controls and are excluded from `FormData`, so core/custom property values were read as empty and the confirmed-write reconciliation path never received the submitted value. Checkpoint 03 normalizes opaque file identifiers with `String(...)` consistently for open, download, and delete, and no longer suppresses the destructive confirmation merely because the pre-confirmation metadata lookup misses. The M50 static and deterministic authorities now explicitly guard both root causes. No Supabase migration, policy, RPC, Storage contract, or M49 predecessor change is introduced by this corrective.

## Checkpoint 07 — SVG event-target ownership corrective — 2026-09-22

The focused Checkpoint 06 browser gate proved that attachment-delete clicks still never created `.board-dialog`.
