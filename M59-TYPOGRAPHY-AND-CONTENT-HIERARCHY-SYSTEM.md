# M59 — Typography & Content Hierarchy System

M59 establishes governed semantic typography roles, content-flow behavior, data typography, typed product references, and additive React primitive support. Existing visual consumers remain compatible and are not mass-rewritten.

## Scope

- display/page/section/subsection hierarchy
- body/body-strong/control/label/caption/helper/metadata roles
- data/data-header, numeric, and code typography
- wrap/truncate/preserve content behavior
- heading-level independence from visual role
- rem-based zoom/text-scaling preservation
- deterministic ownership and certification

## Explicit exclusions

M60 color/theme/contrast, M61 layout/spatial rules, M62 breakpoint-specific typography changes, M63 broader accessibility work, M64 component migration, and later host/module adoption.
